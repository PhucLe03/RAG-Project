\section{Current tasks: late December 2024}

Early development efforts will begin to validate the feasibility of the proposed approach. This includes the data curation, chunking, and setting up local LLM.

\section{Upcoming tasks: January 2025 and Beyond}

\begin{enumerate}
    \item \textbf{Collecting and organizing the dataset (January 2025):}
    Data collection and preprocessing will begin in January, focusing on ensuring dataset quality and relevance.

    \item \textbf{Preparing local LLM and embedding system (January 2025):}
    The local LLM and embedding system will be configured and tested to handle efficient information retrieval.

    \item \textbf{Configuring the vector database (January 2025):}
    A vector database will be set up to store and retrieve embeddings efficiently, enabling core retrieval functionalities.

    \item \textbf{Implementing query handling and prompt management (February 2025):}
    Mechanisms for processing user queries and managing prompts will be developed to ensure smooth user interactions.

    \item \textbf{Evaluating retriever and generator (February 2025):}
    The retrieval and generation components will be assessed for accuracy, efficiency, and performance.

    \item \textbf{Integrating into VSCode (February 2025):}
    The system will be integrated as an extension into VSCode to enhance developer usability and accessibility.

    \item \textbf{Implementing user interface for interactions (March 2025):}
    A user-friendly interface will be developed to facilitate seamless interaction between users and the system.

    \item \textbf{Evaluating the extension's performance (March 2025):}
    Comprehensive performance testing of the VSCode extension will be conducted to ensure reliability and usability.

    \item \textbf{Optimizing the system (March 2025):}
    System optimization efforts will focus on improving speed, accuracy, and overall user experience.

    \item \textbf{Deployment (April 2025):}
    The fully developed and optimized system will be deployed for production use.

    \item \textbf{Writing final report (April 2025):}
    A comprehensive report summarizing the research, development, evaluation, and findings will be prepared and submitted.
\end{enumerate}
